# Catálogos públicos de FUE y capitales catalanas

Comprobación del 4 de octubre de 2026. El contrato de adquisición vive en `@reforma-digital/government/public-catalogues`. Solo devuelve títulos y enlaces de índices públicos; no copia fichas individuales ni confirma sus requisitos. `consultedAt` es la fecha de consulta; `sourceUpdatedAt` solo se rellena cuando el índice muestra una fecha oficial. En la FUE no se observó esa fecha. La integración en guías y en el índice de la extensión queda para un ticket posterior.

La [FUE explica](https://canalempresa.gencat.cat/ca/fue/que-es-la-fue/) que unifica información y coordina administraciones. La [integración XML municipal](https://canalempresa.gencat.cat/ca/fue/Espai-FUE-ajuntaments-tecnics-municipals/complir-normativa-facilitacio-activitat-economica/connectar-sistemes-informacio/informacio-tramits-municipals/) está documentada para ayuntamientos y AOC; no es una API pública de consulta para este proyecto. Por eso se usa el HTML público de rutas exactas. Un 403, una redirección, un cambio de DOM o una licencia sin verificar produce un hueco, nunca la conclusión de que el trámite no existe. No se accede a áreas privadas ni se guardan HTML, HAR, cookies o capturas de sesión.

La [ficha de alta de autónomo de Gencat](https://tramits.gencat.cat/ca/tramits/tramits-temes/Alta-dun-empresari-individual-o-treballador-autonom) no se incorpora como obligación, importe ni regla. Sus versiones catalana y castellana y su vigencia deben comprobarse por pieza contra fuentes competentes antes de redactar una guía; un enlace de catálogo no sustituye esa validación.
