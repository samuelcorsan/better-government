# Alta de persona autónoma: ruta FUE → PAE Virtual

Mapa **parcial y no ejecutable** para [#53](https://github.com/samuelcorsan/reforma-digital/issues/53), observado el **4 de octubre de 2026** con Playwright en páginas públicas. La [guía «Vull ser autònom» de Canal Empresa](https://canalempresa.gencat.cat/ca/01_que_voleu_fer/02_comencar_un_negoci/crear-empresa-constitucio-tramits/vull_ser_autonom) enlaza la [ficha de alta](https://canalempresa.gencat.cat/ca/integraciodepartamentaltramit/tramit/PerTemes/Alta-duna-persona-empresaria-o-treballadora-autonoma), actualizada allí el **21.07.2026**. La ficha muestra «Inicia» bajo «Per Internet», pero ese enlace lleva al [PAE Virtual de CIRCE](https://paeelectronico.circe.es/Account/LoginVirtual?id=10240), un origen estatal distinto. La propia ficha identifica como organismo responsable al Ministerio de Industria. El acceso público de CIRCE solicita identificación con certificado mediante Cl@ve y advierte que el certificado ha de pertenecer a la persona emprendedora.

El único estado estructural comprobado del trámite es la pantalla pública `/Account/LoginVirtual`: botón original `button#send`, `type="submit"`, etiqueta visible «Login Cl@ve», formulario `POST` del mismo origen. `flow-map.json` reconoce ese estado y declara **cero transiciones**: no pulsa la identificación, no pasa valores personales y no sustituye certificado, Cl@ve, Autofirma ni controles oficiales. El parámetro público `id=10240` procede del enlace de la ficha; el contrato `FlowMap` comprueba origen y ruta, no query, y por eso este mapa se mantiene inactivo hasta verificar la identidad del trámite también tras el login.

No se ha usado una sesión autenticada. Quedan sin observar la primera pantalla privada, sus campos, validaciones, estados, posibles cambios de origen y la última pantalla anterior al envío. No hay evidencia de presentación ni respuesta administrativa. Antes de mapear o automatizar esos pasos se necesita una visita técnica manual con una sesión propia, sin guardar HTML, URLs personales, credenciales, valores, capturas ni datos de sesión. La versión del mapa debe cambiar si varía la pantalla; una discrepancia deja la web original.

El test usa un DOM **sintético** que reproduce únicamente el botón público observado y la URL sin datos personales. No verifica una pantalla autenticada ni ejecuta T-004. El mapa no se registra en el catálogo de la extensión.
